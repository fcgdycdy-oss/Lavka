# Лавочка — сайт факультета журналистики ВГУ

## Что есть в проекте
- Главная страница с новостями.
- «Предложка»: студенты могут отправлять новости, идеи, вопросы и события, в том числе анонимно.
- Раздел «Расписание» с выбором курса и группы, автоматическим числителем/знаменателем и данными официального сайта ВГУ.
- Локальный редактор публикаций и входящих предложений: `http://127.0.0.1:8000/admin.html`.
- Данные новостей и предложений хранятся в `lavochka.db` (SQLite) рядом с `server.py`.
- Проект не требует установки дополнительных Python-пакетов.

## Установка в Windows / VS Code
1. Распакуй архив.
2. Скопируй содержимое папки `vsu_jour_schedule` в свою папку проекта, например `D:\opa\Lavochka`. Если Windows спросит, заменить ли файлы, соглашайся. Не удаляй папку `source_dump`, если она у тебя есть.
3. Открой эту папку в VS Code.
4. В терминале выполни `python server.py`.
5. Открой `http://127.0.0.1:8000`.
6. Для публикации новостей и чтения предложки открой `http://127.0.0.1:8000/admin.html`.
7. Чтобы остановить сервер, вернись в терминал и нажми `Ctrl+C`.

## Как редактировать сайт самостоятельно

### Самый простой способ: редактор
- Открой `http://127.0.0.1:8000/admin.html`.
- В форме «Добавить новость» заполни категорию, заголовок и текст и нажми «Опубликовать».
- В блоке «Предложка» читай сообщения, отмечай просмотренные или удаляй ненужные.
- Новости и сообщения сохраняются в `lavochka.db`, поэтому не исчезают при перезапуске сервера.

### Как менять внешний вид
- `styles.css` — цвета, размеры, отступы, карточки, адаптация для телефона.
- `index.html` — структура главной страницы и тексты интерфейса.
- `app.js` — переключение разделов, загрузка новостей, отправка предложки и логика расписания.
- `server.py` — локальный сервер и API; не меняй его, если пока не понимаешь назначение изменений.
- `admin.html`, `admin.css`, `admin.js` — редактор сайта.

В начале `styles.css` есть переменные цветов:
```css
:root {
  --bg: #E9ECEF;
  --ink: #212529;
  --purple: #8338EC;
  --orange: #FB5607;
}
```
Измени значение, чтобы поменять цвет во всем сайте.

### Как менять заголовок на главной
Открой `index.html`, найди `Что происходит` и измени текст внутри соответствующего `<h1>`. Сохрани `Ctrl+S`, обнови сайт `Ctrl+F5`.

### Как поменять название пункта меню
В `index.html` найди кнопки с `data-page-link="home"`, `data-page-link="suggestions"` и `data-page-link="schedule"`. Меняй только видимый текст внутри кнопки, не удаляй `data-page-link`.

### Как поставить настоящий логотип
Пока в шапке стоит текстовый блок `ЛОГО`. Положи изображение, например `logo.svg`, в папку проекта `assets`, а в `index.html` найди `<span class="logo-placeholder" ...>ЛОГО</span>` и замени его на:
```html
<img class="site-logo" src="assets/logo.svg" alt="Лавочка">
```
После этого добавь в `styles.css`:
```css
.site-logo { width: 42px; height: 42px; object-fit: contain; }
```

### Как работает предложка
Форма сохраняет сообщения в локальную базу на компьютере, где запущен сервер. Для текущей версии это локальный прототип: если ты хочешь, чтобы студенты отправляли сообщения со своих телефонов из любой сети, понадобится разместить сервер и базу в интернете. Не выставляй этот локальный редактор в открытый интернет без защиты доступа.

## Шрифты Benzin
В папке `assets/fonts` есть памятка. Если у тебя есть лицензированные webfont-файлы, положи туда `Benzin-Regular.woff2` и `Benzin-Bold.woff2`. Файлы шрифта не включены в архив.

## Примечание
Расписание запрашивается с официального API ВГУ. Для его загрузки нужен интернет и запущенный `server.py`.
