Шрифт Benzin

Положи сюда лицензированные webfont-файлы и назови их точно:
- Benzin-Regular.woff2
- Benzin-Bold.woff2

CSS уже подключает их: regular (400) для обычного текста и bold (700) для заголовков.
Не распространяй файлы шрифта без подходящей лицензии на webfont-встраивание. Официальная страница лицензии: https://www.myfonts.com/collections/benzin-font-supremat
